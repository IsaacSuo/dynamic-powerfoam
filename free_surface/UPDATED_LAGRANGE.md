# 更新拉格朗日 Power 胞模型（推导草稿，2026-10-27）

用户定：模型改为更新拉格朗日（每格带 F 作历史量，每步用当前剖分上的速度梯度更新），时间积分用向后 Euler。本文件是推导、测量与待定问题；代码在 `free_surface/ul_model.py`（torch 参照版）。

## 0. 为什么换，换掉什么

拟合皮模型这几天暴露的问题都来自"几何固定在静止构型、变形后用近似去补"：

- 墙矩按两站点中点放（S_B = Σ (A/2) d nᵀ）。真实墙心离中点 |h/L − ½| 中位 0.07（8k）/ 0.15（lion），站点在墙外的墙 7.6 % / 22.5 %；每格总边界矩 M_t 对 V·I 偏差中位 41–62 %。墙放在真实形心时 M_t = V·I 到机器精度（散度定理）。
- 体积有两个来源（det F_B、Hermite 墙通量 J），会反着走（6926、2676）；变形后边界不闭合（缺口中位 1–2 %，p99 7–14 %）。
- 小格子被邻居挤穿、F_B 翻面后 R 的奇点（σ2 = σ3）卡死求解。
- 渲染要另猜半径（r0 J^(1/3)），与模型几何不是同一个东西。

新模型保留：站点（刚体位置即格子的生成点）、Power 胞 ∩ 球的剖分结构、增量势 + 信赖域 Newton-CG。去掉：平行连接、拟合皮闭合式（方案 A）、Hermite 体积项、方差项、rot_proper。

## 1. 状态与一步

状态：站点 x_i、速度 v_i、每格变形梯度 F_i（相对静止构型）、权重 w_i = r_i²；质量 m_i = ρ V0_i 不变。

第 n 步 → n+1：

1. 剖分：在 (x^n, w^n) 上建 Ω_i = L_i ∩ B(x_i, r_i)（L_i 为 Laguerre 胞）。得到墙 (i, j)：面积 A_ij、形心 c_ij、法向 n_ij = (x_j − x_i)/ℓ_ij（ℓ_ij = |x_j − x_i|）、沿连线的位置 h_ij = (c_ij − x_i)·n_ij、切向偏移 t_ij = c_ij − x_i − h_ij n_ij；胞体积 V_i；球冠 K_i（自由面）。用 `recut.Recut.geometry`（GPU，8k 上 65 ms）。
2. 梯度算子：线性映射 G_i：{Δx_k} ↦ ∇Δu_i（3×3），只在步初几何上建一次，步内不变（§3）。
3. 试探变形：F_i(x) = (I + G_i(x − x^n)) F_i^n。
4. 增量势（向后 Euler）：
   Π(x) = Σ_i m_i/(2Δt²) |x_i − x_i^n − Δt v_i^n|² + Σ_i V0_i ψ(F_i(x)) + E_c(x) − Σ_i m_i g·x_i，
   用信赖域 Newton-CG 求 x^{n+1} = argmin Π。步内几何不变 ⇒ Π 是 x 的光滑函数，拓扑变化（墙出生、消失）只发生在步与步之间。
5. 更新：v^{n+1} = (x^{n+1} − x^n)/Δt，F_i^{n+1} = F_i(x^{n+1})。
6. 体积贴合：在 x^{n+1} 上解权重，使 V_i(x^{n+1}, w) = V0_i det F_i^{n+1}（§6，`recut.solve_radii`）。

ψ 取任意超弹性（先用 neo-Hookean：ψ = μ/2 (tr FᵀF − 3) − μ ln J + λ/2 (ln J)²），对数项使 J > 0；不需要 F 的极分解。屈服、断裂以后加在步 5 的 F 更新上（乘法分解 F = F_e F_p）。

## 2. 剖分的几何恒等式

对每个格子（墙 + 球冠围成闭合边界）：

- 闭合：Σ_j A_ij n_ij + a_i = 0，a_i = ∫_{K_i} ν dA。
- 一阶矩：Σ_j A_ij (c_ij − x_i) ⊗ n_ij + M_i = V_i I，M_i = ∫_{K_i} (y − x_i) ⊗ ν dA = r_i ∫_{K_i} ν νᵀ dA（球冠以站点为球心）。

在 8k jack 与清理后的 lion 上用精确几何核过：两式都到机器精度（`tmp/wall_lever.py`，M_t 对 V·I 0.000）。

连续性：V_i 对权重 w 的导数 ∂V_i/∂w_j = −A_ij/(2ℓ_ij)（j ≠ i），∂V_i/∂w_i = Σ_j A_ij/(2ℓ_ij) + A_{K,i}/(2 r_i)（`recut.py`，对中心差分核过 1.5e-8）；墙出生、消失时面积为 0，故 V 对 w 是 C¹（半离散最优输运的已知结论）。对站点位置 x 同样应是 C¹（体积只随边界的法向速度变化），**待数值核实**。本模型里拓扑只在步间变化，步内用不到这一点；它关系到"步间重切是否给 F 的更新带来跳变"（§3 末）。

## 3. 梯度算子 G_i（问题 1）

要求：(a) 线性场精确：若 Δx_k = a + B x_k（所有 k），则 G_i = B（分片检验）；(b) 平移不变；(c) 尽量接近格子平均梯度 (1/V_i)∮ Δu ⊗ ν dA（KB §14：现有 F_B 估计对真实格子平均梯度差 25–60 %）。

### 3.1 候选 L：面积加权最小二乘

G_i = [Σ_j ω_ij (Δx_j − Δx_i) ⊗ d_ij] [Σ_j ω_ij d_ij ⊗ d_ij]⁻¹，d_ij = x_j^n − x_i^n，ω_ij = A_ij/ℓ_ij。

- 线性场精确（只要邻居张成三维）；表面格子单侧拟合对线性场仍精确。
- 它就是现在内部格子的 F_B：Σ (A/ℓ) d ⊗ (ℓ n) = Σ A d nᵀ = 2 S_B，Σ (A/ℓ) ℓ² n nᵀ = 2 M_b ⇒ G = S_B M_b⁻¹（只是现在放在当前构型、对增量用）。
- 自己的位移以 −Δx_i ⊗ Σ_j A_ij n_ij = Δx_i ⊗ a_i 出现：内部格子 a_i = 0 ⇒ 内部格子的 G_i 与自己站点无关（§4）。
- 不是格子平均梯度（权重 ω 不来自散度定理），对非线性场有一阶误差。

### 3.2 候选 D：在当前闭合边界上用散度定理

V_i G_i = Σ_j A_ij ū_ij ⊗ n_ij + ∫_{K_i} Δu ⊗ ν dA，ū_ij 为墙 W_ij 上 Δu 的平均。

- 线性场时 ū_ij = Δu(c_ij)。沿连线在墙平面处线性插值（对线性场精确，h 在 [0, ℓ] 外也成立）：Δu(x_i + h n) = (1 − h/ℓ) Δx_i + (h/ℓ) Δx_j；切向偏移 t 需要梯度：Δu(c) = Δu(x_i + h n) + B t，取 B ≈ ½(G_i + G_j)。
- 球冠：Δu 在冠上由本格外推，Δx_i + G_i (y − x_i)，贡献 Δx_i ⊗ a_i + G_i M_i。
- 代入并用闭合式消去 Δx_i 的绝对值：
  Σ_j A_ij h_ij (G_i n_ij) ⊗ n_ij + ½ Σ_j A_ij (G_i − G_j) t_ij ⊗ n_ij = Σ_j A_ij (h_ij/ℓ_ij)(Δx_j − Δx_i) ⊗ n_ij。
  这是所有格子耦合的线性方程组（经 t 项）；G_i ≡ B 是线性场的精确解。t ≡ 0 时退化为每格独立的 G_i = [Σ A (h/ℓ) Δd ⊗ n][Σ A h n nᵀ]⁻¹，即 L 把杠杆 ℓ/2 换成真实的 h。
- 优点：是格子平均梯度的二阶近似，用的是真实的墙位置。缺点：要解耦合方程（与方案 A 的耦合闭合同类，lion 上块 Jacobi ρ 0.79）；表面格子的 Σ A h n nᵀ 在外法向上缺信息（与拟合皮闭合式的弱方向是同一件事，§5）。

建议先用 L 搭起整个流程（简单、每格独立、已知它在内部格子上就是现在的 F_B），D 作为精度升级；两者都在分片检验与 KB §14 的光滑非均匀场上量。

## 4. 零能模态（问题 2）

任何对线性场精确的单点梯度 G_i = Σ_j c_ij (Δx_j − Δx_i) 都可能有"每个格子的 G 都为 0、但位移不是刚体"的模式（有限体积 / 节点积分里的沙漏、棋盘模式）。候选 L 中内部格子看不见自己站点，最典型。拟合皮模型里这一角色由连接承担。

检验：零件上组装 K = Σ V0 Gᵀ C G（线化），数零特征值；应只有 6 个刚体模态（3 平移 + 3 转动：G = 反对称时线化能量为 0）。再在规则晶格上看棋盘模式。

若有多余零模态，稳定项候选（不破坏分片检验）：每面墙的非仿射跳变
δ_ij = Δx_j − Δx_i − ½(G_i + G_j) d_ij，E_hg = Σ_walls β_ij |δ_ij|²。
线性场时 δ = 0。刚度 β_ij 的量纲是 μ A/ℓ（面上的应变跳变 δ/ℓ、作用面积 A、作用长度 ℓ）。系数必须由连续体对照推出来（或由零件模态检验而非拟合），**未推**。

## 5. 自由面（问题 3）

变分形式里，自由面是自然边界条件：能量只有 Σ V0 ψ(F_i)，表面不加任何力，平衡时表面无牵引自动成立；不需要拟合皮那套闭合式。要求只是表面格子的 G_i 由运动学定得住：

- 候选 L：邻居张成三维即可（单侧也行）。只有一两层格子厚的薄片，邻居近共面，Σ ω d ⊗ d 在法向上退化 ⇒ G_i 的法向列定不住。
- 候选 D：表面格子的 Σ A h n nᵀ 在外法向上缺信息，问题相同。

退化方向上不能靠阈值区分。可推的做法：把格子在该方向上的 G 分量作为局部未知量，对 ψ 取极小（静态凝聚：∂ψ/∂(F m) = P m = 0，正是无牵引条件），不需要权重；难点是"哪些方向算退化"要用连续的方式定，**未推**。先量：8k、30k、lion 上表面格子的 Σ ω d ⊗ d 条件数分布，看薄片格子有多少。

## 6. 体积贴合（步 6）

在 x^{n+1} 上解 w 使 V_i(x^{n+1}, w) = V0_i det F_i^{n+1}：半离散最优输运的阻尼 Newton（`recut.solve_radii`，解析对称雅可比，8k 上每次 340–390 ms）。

- 体积只由 F 定（本构里的 J = det F），剖分只负责几何（墙、球冠、接触球）；总体积 Σ V0 det F。
- 表面格子的半径随之变，自由面的形状由当前球冠给出。
- 可能失败的情况：某站点被完全遮住（胞消失）。recut 先把它的权重提到占住自身位置；物理上意味着该格子被挤没，需要处理（合并质量？）——**待定**。

## 7. 接触

先保持赫兹球心接触（球半径 = 当前 r_i），能量加在 Π 里。

## 8. 时间积分：向后 Euler

Π 如 §1；数值耗散：频率 ω 的振动每步能量乘 1/(1 + ω²Δt²)，小 ωΔt 时等效阻尼比 ζ ≈ ωΔt/2。Δt = 1/1200 时 ω = 100 rad/s 的模态 ζ ≈ 0.04；Vid2Sim 真值是 Δt = 0.05 的向后 Euler，同一模态 ζ ≈ 2.5（过阻尼）。向后 Euler 本身不会自动对上真值的耗散，除非步长相同。

## 9. 计算量（8k，估计）

每步：一次剖分 + 解权重约 0.4 s；Newton 内部每次求值只有 F_i(x)、ψ 和接触，没有耦合闭合，比现在一次梯度便宜（未测）。lion 0.5 s 600 步约 4–5 分钟（单跑）。

## 13. 塑性接进增量势（推导，未实现）

状态：每格 F_i（总）、F_p,i（塑性）、α_i（等效塑性应变）；弹性部分 F_e = F F_p⁻¹。

1. **本构更新写成极小化（Ortiz–Stainier 变分本构更新）**：每格在步内的能量取凝聚后的增量功函数
   W_i(F) = min_{塑性增量} [ψ_e(F_e) + ψ_h(α) + 耗散(Δα)]，
   对 Hencky 弹性 + J2（von Mises）+ 关联流动，极小点就是对数应变空间里的径向回映（闭式）：
   试探 b_e^tr = F (F_p^n)⁻¹(…)ᵀ，ε^tr = ½ log b_e^tr；τ_dev = 2μ dev ε^tr；f = |τ_dev| − √(2/3)(σ_y + Hα^n)；
   屈服时 Δγ = f/(2μ + 2H/3)，ε_e = ε^tr − Δγ n̂，α += √(2/3)Δγ。
   于是 Π(x) = 惯性 + Σ V0 W_i(F_i(x)) + 接触 + 稳定项，仍是 x 的极小化，信赖域 Newton 照用。dW/dF（回映后的应力）在屈服面上连续，切线刚度跳变（Newton 可接受；"事件力连续"满足）。
2. **为什么新模型能做而旧模型不行**：旧模型 F_B 每步由站点位置经闭合式算出，没有地方存 F_p（10-26 塑性在橡皮泥落地时不稳、被搁置，疑点"步末外推"）。新模型 F 本身是状态。
3. **稳定项在塑性下**（S-NSNI §6，式 66–76）：非线性时稳定项需要的是应力梯度 = 试探（弹性）梯度 − 塑性修正的梯度；塑性修正的梯度由各节点的修正值插值再求导得到；用"估计模量"在软化问题上发散。能量写法的对应：稳定项作用在弹性应变的格间变化上
   E_stab = ½ Σ_i Σ_kl J_i^kl ∂_k e_i : C : ∂_l e_i，e_i = 格子 i 的空间 Hencky 弹性应变（½ log b_e，随标架转动，相邻格子之差客观），∂_k e_i 用与 §12 S-NSNI 相同的平滑（墙上按 h/ℓ 插值、球冠取本格、对称化）。
   e = ε − ε_p ⇒ ∂e = ∂ε − ∂ε_p，正是论文"试探梯度 − 修正梯度（由节点值插值）"的结构；弹性时退化为 §12 的形式（小变形）。它是步内 x 的函数（经回映），变分结构保留。
4. **跳变项在塑性下**：用总 F（含塑性）预测相邻站点的相对位置，只罚格子尺度的非仿射部分，不阻挡仿射的塑性流动。大塑性流动后邻居会换，参考构型里相距很远的两格可能成为邻居，用参考坐标差 X_j − X_i 会给出假跳变 ⇒ 改为每面墙的增量历史：
   δ_f^{n+1} = R_f δ_f^n + (Δx_j − Δx_i − ½(ΔG_i + ΔG_j) d_f^n)，R_f 为墙在步内的转动；新出生的墙 δ = 0（面积也从 0 开始，连续）；消失的墙历史随之丢弃（面积已到 0）。
5. **待定**：硬化与率相关（粘塑性可直接加在耗散里）；体积塑性（土、雪需 Drucker–Prager 一类）；稳定项里用空间 Hencky 应变之差还是 F 之差，大转动下需核客观性与精度；回映的切线是否要用一致切线（TR Newton 的乘积用差分，可以不用解析切线）。

## 14. 跳变项改成内聚界面：断裂（推导，未实现）

1. **每面墙一个损伤 d_f ∈ [0, 1]（历史，只增不减）**：墙的能量 φ_f(δ_f, d_f)；未损伤时 = §12 的跳变能 ½ δᵀK_f δ，K_f = (A/3ℓ)(μ I + (λ+μ) n nᵀ)。软化律（例：线性软化）：法向牵引 t = (k/A)δ 到峰值 σ_c（材料强度），之后线性降到 0，牵引–张开曲线下的面积 = G_c（断裂能，材料参数）。σ_c、G_c 是材料参数，不是数值阈值。
2. **只降界面能不够**：两格分开时，它们的梯度 G_i、G_j 仍把对方算作邻居，裂开会被当成格子的拉伸，体内能量照样阻止开裂。⇒ 损伤同时降低这面墙在所有算子里的权重：L 的最小二乘权 ω_f → (1 − d_f) A/ℓ，S-NSNI 平滑里墙的贡献乘 (1 − d_f)，跳变能乘 (1 − d_f)（或由软化律给出）。d_f = 1 时这对格子在材料上完全断开，裂面成为两侧格子的自由面（单侧拟合，§5 的问题在裂面上同样存在）。权重连续变化 ⇒ 力连续，"事件力连续、切向导数可传"满足。
3. **损伤的更新**：变分断裂的做法——每步对 (x, d) 联合极小，d ≥ d^n（不可逆）；实际用交替：固定 d 解 x（现有 TR Newton），再逐墙闭式更新 d，至收敛。
4. **剖分与材料连接分开记**：剖分里的墙表示几何上相邻；材料是否连着由每对格子的状态决定。裂开后两侧再接触，剖分会重新长出墙，但它们不应重新粘上（只接触、不穿透）。新出生的墙是否算"连着"：候选规则——两格有共同的、两边都完好的邻居 ⇒ 连着（同一完好邻域内的邻居更替，如塑性流动），否则不连（跨裂缝）。需推敲。
5. **其他问题**：裂纹只能沿格子墙走（路径依赖剖分，随机 Power 胞统计上近各向同性）；裂面露出的是格子内部，渲染纹理未训练过（与"内部格子露出"同一问题）；参数辨识时 d 的更新要可微（软化律光滑、交替极小收敛）。

## 17. 提速（2026-10-27 晚；默认改为挪位移 + 形心连线插值）
