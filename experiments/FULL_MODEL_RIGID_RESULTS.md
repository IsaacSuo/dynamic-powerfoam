# 原始完整 forward 的小规模刚体坐标检查

日期：2026-09-25。入口：[full_model_rigid_probe.py](full_model_rigid_probe.py)。

## 问题与边界

在原始 `PowerfoamScene.forward()` 中启用局部空间纹理、非零位移和 Spherical Voronoi
视角相关颜色后，对场景与相机同步作刚体坐标变换，渲染是否基本不变？

这是自编的受控输入和变换检查，使用原模型完整前向，不是论文实验复现。
没有重新实现纹理插值或 renderer，也没有训练、MPM、非刚性形变或动态重建质量评价。
参数是人工构造的：绕过数据集初始化，直接赋给原始 scene 参数；不调用旧 probe 的底层渲染包装。

## 设置

- 分别 1 和 9 个 cell，192×192 图像，固定随机种子 25。
- 每个 cell 有 8 个局部 detail sites，每个 site 有 8 个非零 SV 方向轴。
- site 的空间颜色不同，高度非零且不相同，密度为 8，半径为 0.52。
- 9 cell 情形有球重叠和 power 面裁剪；单 cell 情形没有邻居裁剪。
- 完整调用 `scene.forward → SV → Rasterizer.forward`，每次更新后重新建立原始 Čech 邻接。
- 场景与相机同步旋转（SciPy 小写 xyz Euler，24°、−31°、17°），平移 (0.3,−0.2,0.4)。

原始四元数生成的 frame 以法向和切向为行。若世界旋转为 Q，则变换为 `frame @ Q.T`。
中心与相机位置变换为 `Q p + b`，相机方向和 SV 轴都乘 Q。
局部二维坐标、高度、半径、密度、SV 颜色与温度不变。
world sites/heights 由原 `scene.forward()` 重新生成，实验没有手工替换这些中间结果。

**旋转 SV 轴在这里属于坐标变换。** 不能据此推断真实物体在固定世界光照下转动时，
辐射函数一定刚性随动；后者需要另行定义照明与外观假设。

## 结果

RGB 范围约为 0–1。前景是两图 alpha > 0.05 的并集，不用大片背景稀释误差。

| 对照 | 1 cell 前景 RGB MAE | 9 cells 前景 RGB MAE |
| --- | ---: | ---: |
| 完整刚体坐标变换 | 0.00001101 | 0.00002856 |
| 故意漏掉 frame 旋转 | 0.124625 | 0.101191 |
| 故意漏掉 SV 轴旋转 | 0.027769 | 0.039400 |
| 原坐标下把高度置零 | 0.037635 | 0.024263 |
| 原坐标下把各 site 的 SV 颜色参数取空间均值 | 0.095831 | 0.116353 |

完整变换的最大单通道误差分别为 0.003745 和 0.008951；两组均无像素最大通道误差超过 0.01。
双侧有效像素的中位透射深度 MAE 分别为 7.31e-7 和 2.34e-5。
报告残差，没有把结果写成逐位相等，也没有将残差归因到某一个未经隔离验证的浮点步骤。

漏转 frame 同时影响 dipole、site 世界位置和位移朝向，是一个组合负对照，不能拆算三者各自贡献。
“颜色取均值”只统一 SV 颜色系数；各 site 仍有各自的方向轴，因此它不是严格的 cell 内常色对照。
这些对照用于确认机制有可测影响，误差大小不是各模块的性能排名。

## 解释与后续

在这个小输入下，原始完整前向与正确的刚体坐标变换基本一致；局部纹理、位移和 SV 外观都实际参与结果。
这明确了一个完整随动适配器需要处理哪些量。它没有检验梯度、拟合能力、时间插值或非刚性运动。

后续小实验可在此基础上只增加一个因素，例如局部剪切，明确所用的参考形变与外观输运规则，
分别检查空间分区、局部表面和纹理查询；不能只用 cell 标签误差替代图像/表面误差。
是否随后引入时间优化或原生四维分区，应依据那些具体结果决定。
