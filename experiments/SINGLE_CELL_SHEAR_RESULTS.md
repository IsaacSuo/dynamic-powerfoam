# 单 cell 剪切：局部控制点与位移能补偿什么

日期：2026-09-25。入口：[single_cell_shear.py](single_cell_shear.py)。
这是一个自编的受控输入实验，参考和待拟合模型均调用原始 `PowerfoamScene.forward()`。
没有重新实现空间纹理、位移查询、SV 或渲染器；没有修改核心代码。

## 1. 问题与参考目标

从一个有 8 个 detail sites、非零位移、每 site 8 个 SV 方向轴的人工 cell 出发，施加

```text
x' = x + k y, y' = y, z' = z; k = 0.5 或 1.0
```

测试调整局部二维控制点、再联合调整位移值，能否拟合原 cell 的细节输运。
中心、半径 0.52、dipole 朝向、密度 8、SV 方向轴与颜色系数在所有待拟合模型中固定。
这里没有 cell 竞争或增删。

**参考不是一个另写的 renderer。** 对每条世界射线，把原点与方向乘 F 的逆矩阵，
将变换后的同源射线通过原始 generic-ray forward 送入 canonical cell。
原始 dipole 位移和两次空间查询、SV 颜色均由原代码执行。
这定义了一个“把 canonical 渲染查询经仿射映射搬运”的参考：

- 它是明确的材料外观输运约定，不是固定世界光照下真实物体的物理渲染。
- 原始位移求交是一次查询近似，不能把参考称为任意连续高度场的精确变形 mesh。
- 源 SV 查询使用逆变换后的相机；待拟合模型使用世界相机、自己的 world sites 和固定 SV 参数。
  所以颜色残差包含原模型的方向查询变化，不仅是空间插值权重误差。

设 `s=||F^-1 d_world||`，canonical 单位射线参数满足 `t_can=s*t_world`。
原始 forward 返回单 cell 的 premultiplied RGB、alpha 和 0.5 透射率分位深度。
用 RGB/alpha 取出此次查询的颜色。保持世界消光系数 sigma=8 时：

```text
alpha_world = 1 - (1-alpha_can)^(1/s)
t_entry_world = (t_median_can - log(2)/sigma) / s
```

深度公式只在有有效中位深度的前向进入区间成立；内部评分区对此做了限制。
“表面误差”在本报告中特指这项**入口射线距离误差**，不是 Chamfer distance 或三维全表面误差。

## 2. 对照与拟合

| 对照 | 可改变的参数 |
| --- | --- |
| unchanged | 全部保持原状 |
| advected_sites | 将 site 的世界位置乘 F，再投影回原局部坐标；高度保持不变 |
| fit_sites | 从 advected_sites 开始，仅优化 8 个二维局部坐标 |
| fit_sites_and_heights | 同时优化上述坐标与 8 个局部高度 |

后两者各用 Adam 300 步，学习率 0.005。损失是内部颜色 MSE 加入口距离除以原半径后的 MSE。
局部坐标约束在 [-1.5,1.5]，局部高度在 [-0.45,0.45]；本次最优联合拟合均未触及约束边界。
仅按训练损失选择参数，不使用报告视角或报告分辨率选模型。

训练只有正面 96×96 图像。报告使用相同视角 192×192，以及未参与拟合的偏转 12° 相机。
这不是原论文的全损失训练，也不优化外观系数，不做 densification。
使用原有手写反向，没有在本实验完成有限差分审计；所报残差不是表达能力下限或优化全局最优值。

内部评分区固定为：基准面交点在 world 与 canonical 中都距中心小于 0.7r，
且参考有有效中位深度、目标 alpha>0.55。评分区不随拟合参数变化。
因此不把球界不匹配计入“内部细节误差”，而在第 4 节单独报告。

## 3. 细节误差

颜色为除去 alpha 后的 RGB MAE，数值尺度约 0–1；几何列为入口距离 RMSE/r。
表中每个单元格为 **颜色 / 几何**。所有对照在评分区都没有缺失的中位深度。

| 剪切与报告视角 | 不变 | site 直接搬运 | 仅拟合 sites | 联合 sites + heights |
| --- | ---: | ---: | ---: | ---: |
| k=0.5，同视角高分辨率 | 0.02019 / 0.02224 | 0.02011 / 0.02222 | 0.01139 / 0.00943 | 0.01122 / 0.00679 |
| k=0.5，未见 12° 视角 | 0.01641 / 0.02277 | 0.01908 / 0.02266 | 0.01069 / 0.00963 | 0.01064 / 0.00693 |
| k=1.0，同视角高分辨率 | 0.03216 / 0.03480 | 0.03267 / 0.03409 | 0.01728 / 0.01791 | 0.01594 / 0.01103 |
| k=1.0，未见 12° 视角 | 0.02668 / 0.03558 | 0.03135 / 0.03536 | 0.01616 / 0.01833 | 0.01516 / 0.01128 |

较强剪切下，相比不变参数，联合拟合使同视角内部颜色误差降低约 50%，入口距离误差降低约 68%。
直接搬运 sites 没有获得类似改善，未见视角的颜色甚至变差。
这表明“控制点直接随 F 移动”和“重新优化控制点以拟合输运后的细节”是不同操作。
不能由此声称所有剪切、纹理或优化设置都会有相同幅度的改善。

## 4. 固定球界的覆盖与整图结果

用射线与球/逆变换球的解析相交单独统计支撑覆盖；这里只测整个 bounding support，
不是最终 dipole 实体或像素可见表面的覆盖。

| 剪切 | 目标支撑射线未被固定球覆盖的比例 | 固定球额外覆盖比例 | 支撑 IoU |
| --- | ---: | ---: | ---: |
| k=0.5，正面 | 15.46% | 15.37% | 0.733 |
| k=1.0，正面 | 29.51% | 29.32% | 0.545 |

这些数值在所有参数对照中相同，因为实验固定了中心和半径。
这是当前隔离实验的限制，不能据此否定允许半径变化、多个 cell 或重分配的方案。

局部改善也没有变成相同幅度的整图改善：k=1.0 正面 premultiplied RGB 全图 MAE
从 0.04286 变为 0.04225；未见视角从 0.04027 变为 0.04049，略有上升。
整体球界不匹配仍存在，而优化只监督固定内部区域。

## 5. 检查与遇到的问题

- 原始 generic 与 pinhole 路径在同一正常相机下，RGB 全图 MAE=8.70e-7、最大误差=3.76e-4。
  最初要求最大差低于 1e-5 未满足；保留实测值，检查改为均值 <1e-5 且最大值 <1e-3。
  两路径的射线归一化计算不同，未把这项检查表述为逐位相等。
- F=I 的参考输运自检：内部颜色 MAE=2.67e-9，入口距离 RMSE/r=9.95e-7。
- 图像非空，优化损失与参与更新的梯度均为有限值。
- 最初采用半视角向量长度 0.105、相机距离 8 时，源 cell 被整体剔除。
  `count_visible_*` 中 `dot(center-eye,cross(up,right))<0.1` 使用了未归一化的朝向，
  此时为 8×0.105²=0.0882。参考相机的辅助 frame 更宽，没有被剔除，恒等检查因此失败。
  改用 0.15 后为 0.18，绕开该已有接口问题，并加入非空检查。没有修改裁剪代码。

## 6. 能得出的结论

这个单 cell、两档剪切、固定 SV 参数的受控例子表明：原始局部坐标和位移确实有可利用的补偿能力，
之前将其冻结后仅讨论球界/材料标签，遗漏了真实存在的自由度。
同时，直接搬运局部控制点不等于保持其插值场；内部补偿与外部支撑覆盖需要分别评价。

尚未测试完整参数联合优化、多 cell 接缝、时间连续性、原生 4D 分区或 MPM。
下一项小实验应在两个相邻 cell 上检验连续参考细节经过形变后的跨 cell 匹配，
并允许双方局部参数协同调整，而不是人为设置互不相干的红蓝颜色制造接缝。

```bash
conda activate om
python -m experiments.single_cell_shear
```

- `results.json`：恒等检查、训练轨迹、两种视角下的全部指标和支撑统计。
- `shear_1.0_same_view_dense.png` 等四张对照图。白线为固定内部评分区；图内误差只显示该区域。
- 每档剪切与各对照的 `.npz` 参数，可供复查或后续使用。
